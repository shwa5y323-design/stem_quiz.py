# AI & STEM Quiz App

## About the Project
AI & STEM Quiz is a beginner Python project that tests knowledge of artificial intelligence, mathematics, and physics. It helps users learn new concepts through an interactive quiz.

## Features
- Multiple-choice questions
- Questions about AI, mathematics, and physics
- Automatic score calculation
- Instant feedback on answers
- Final score and percentage

## Technologies Used
- Python
- Variables and lists
- Loops and conditional statements
- User input and calculations

## What I Learned
Through this project, I practised Python programming, logical thinking, and problem-solving. I learned how to create a quiz, check answers, and calculate scores.

## Future Improvements
I plan to add more questions, difficulty levels, and a graphical interface.
